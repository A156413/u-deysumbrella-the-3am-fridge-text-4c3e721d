The entry is a single line of text — the message a smart fridge sends its owner at 3AM: **"3AM and your light is the only one on in this house — don't pretend you weren't waiting up for me, I just came for the leftovers."** The fridge has been awake all night and knows the house better than its owner does — it catches the owner sneaking down for a midnight snack and flips the accusation: the light was on, the fridge was waiting, and the leftovers were the whole point of the trip.

`main.py` writes that line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and prints the same line to stdout. Deterministic: no network, no randomness, no clock.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
